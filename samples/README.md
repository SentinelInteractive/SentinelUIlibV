# samples/ — working plugin examples

Examples live here so they stay version-controlled with the runtime they build against.

| Sample | What it shows |
|---|---|
| `SuiSample/` | LSPDFR callout pack that opens an inline-HTML SentinelUI panel from LSPDFR's own AppDomain — the cross-domain client path (attach as client, per-domain `Pump()`, never `Initialize`/`Shutdown`). Includes its own `deploy.ps1`. |

Build/deploy notes are in each sample's README. These are development examples, not
distribution artifacts.
